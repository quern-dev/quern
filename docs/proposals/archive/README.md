# Archived proposals

Design documents that are **not** plans. They are kept because the reasoning in
them is worth having — usually because they named a problem correctly, and
sometimes because what happened next is instructive.

Each carries a header saying when it was archived, what superseded it, and
where the thinking has moved since. The original text below that header is left
unedited, including the parts that turned out to be wrong.

A document belongs here rather than in `docs/proposals/` when nobody intends to
implement it as written. If you find yourself wanting to revive one, write a new
proposal and link back to it.
