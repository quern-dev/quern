# UI automation: screens, taps and landmarks

*`quern://guide/ui` -- part of the Quern agent guide. Start from `quern://guide`.*

Reading what is on screen and acting on it.

This topic is split into pages, one per subject. Read the one you need:

- `quern://guide/ui/reading` -- Reading the screen: get_screen_summary vs get_ui_tree vs screenshots, and keeping reads small
- `quern://guide/ui/tapping` -- Tapping and gestures: tap_element and its selectors, when coordinates are fine, obstructed taps, swipes and typing
- `quern://guide/ui/waiting` -- Waiting for the screen: wait_for_element and wait_for_settle instead of polling
- `quern://guide/ui/debugging` -- Debugging UI issues: summary vs full tree, launches that did not happen, elements off screen, the platform normalizer, an empty screen, web lookups
- `quern://guide/ui/off-screen` -- Reaching elements off screen: scroll_to_find, scroll_to_element, and finding a row's identifier
- `quern://guide/ui/landmarks` -- Identifying Screens with Landmarks: naming screens with a knowledge base: identify_screen, load_landmarks
- `quern://guide/ui/mistakes` -- Mistakes to avoid: ambiguous labels, missing elements, typing over old text or autocorrect, simulator backends
- `quern://guide/ui/troubleshooting` -- When something is wrong: no element found, a wait that timed out, a tap that does not register or hits the wrong element
